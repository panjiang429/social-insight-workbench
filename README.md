# 作品 01 · 社媒洞察工作台

蓝色光标 2027 校招「AI 营销解决方案专员」测评作品 · 作者：江盼（香港城市大学 BISMIS）

对应 JD 职责一：**运用 AI 洞察工具挖掘数据，为品牌制定 AI 驱动的营销战略。**

## 这是什么

把散落的用户评论变成一页能拿给客户看的洞察简报：情绪结构、高频讨论点、话题拆解、代表原声、行动建议。每条结论都能在「核对表」里回溯到原始评论。

## 怎么跑

单文件应用：直接双击 `index.html`，或推到 GitHub 仓库开启 Pages 后用链接访问。无需安装、无后端、无外部依赖。

## 核心逻辑

1. **中文 n-gram 抽词**：2-3 元词频统计 + 词长加权 + 停用词/边界字过滤，自动合并被包含的短词；
2. **情感词典打分**：含「不 / 没 / 无」否定翻转，输出每条评论的正负分与命中词；
3. **主题规则归类**：按主题词命中数归入效果功效 / 质地肤感 / 包装设计 / 价格 / 物流 / 客服 / 香味，附代表原声；
4. **简报生成**：默认规则引擎（离线可用）；右上角配置大模型后可一键由模型改写为策略稿，输出会标注来源。

## 数据声明

内置 40 条评论为**虚构示例**，仅演示算法，不对应任何真实品牌或平台采集数据。真实使用时粘贴自有评论即可，全部计算在浏览器本地完成，不上传服务器。
